# Dibujos de técnica: créditos y licencia

Los dibujos de esta carpeta son una **obra derivada** de las ilustraciones de **Everkinetic**
(https://github.com/everkinetic/data), de Greg Priday / everkinetic.com, publicadas con licencia
**Creative Commons Atribución-CompartirIgual 4.0 Internacional (CC BY-SA 4.0)**:
https://creativecommons.org/licenses/by-sa/4.0/deed.es

## Cambios sobre el original
- Se quita el relleno blanco y se deja solo el trazo, que la app usa como máscara y pinta con los colores del tema.
- Se recortan y se eligen dos fotogramas por ejercicio: el de inicio ("1 · Empiezas") y el final ("2 · Llegas y vuelves").
- Algunos ejercicios de BUDDY usan el dibujo de una variante parecida; la app lo indica bajo el dibujo.

Los genera `scripts/dibujos/generar.mjs` a partir de un clon de Everkinetic, con el mapa de `scripts/dibujos/mapa.json` (decisión D74).

## Licencia de esta carpeta
Como obra derivada, los dibujos de `public/ejercicios/` se distribuyen con la **misma licencia, CC BY-SA 4.0**. Bajo cada dibujo, la app muestra el crédito: "Dibujo: Everkinetic, CC BY-SA 4.0, adaptado."
